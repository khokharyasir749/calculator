# 🧮 Calculator

A simple and responsive calculator built using **HTML, CSS, and JavaScript**.

This project was created as a beginner web development project to practice JavaScript logic, DOM manipulation, and responsive frontend design.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal numbers
- 🧹 Clear button
- ⌫ Delete button
- 📱 Responsive design
- 🎨 Clean and simple interface
- ⚡ Interactive calculator buttons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
